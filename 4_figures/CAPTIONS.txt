Figure and table files
======================
Formatted per the target journal's author instructions for figure files, table
files, figure and table referencing, table styling, and figure styling.

Each figure and each table is supplied as a SEPARATE file (not embedded in the
manuscript). Cite them in the text in ascending order. Enter the title + legend
below for each item during online submission.

Formatting applied:
  - Tables: page margins set to 2.5 cm on all sides (journal requirement);
    columns rescaled to fit within the printable width; roman black text;
    title above table, footnote below; bold emphasis explained in the legend
    (Tables 2 and 3).
  - Figures: PNG, RGB, white background, labelled axes, no embedded overall
    title/legend (multipart panel headers on Figure 2 are panel identifiers).
  - Filenames follow the form 'Figure_1.png' / 'Table_1.docx'. If the journal
    requires a space rather than an underscore, rename on upload.

----------------------------------------------------------------------
FIGURE TITLES & LEGENDS
----------------------------------------------------------------------
Figure 1. Data and evaluation pipeline.
  From the LBOX OPEN drunk-driving subset through duplicate reconciliation
  (test2 subset of test -> 1,500 unique cases), lawyer-verified factor extraction
  (98.5% accuracy), the eight ML configurations and four LLM configurations, to the
  prediction (RQ1, RQ2), explanation (RQ3), and temporal-robustness analyses.

Figure 2. Error geometry and LLM bias.
  Row-normalized (recall) confusion matrices for the best ML model (SVM + TF-IDF)
  and the two zero-shot LLMs, with a predicted-versus-true class-share strip below
  each panel. The ML model spreads predictions across all four classes, whereas the
  LLMs collapse in opposite directions: GPT-5 onto the minority short-sentence class
  (69% of its predictions are class 1, against a true share of 7%), and Qwen3-8B onto
  the majority medium class (80% class 2, with zero recall on the fine/none class).

Figure 3. Global SHAP factor importance (r_ML).
  Mean absolute SHAP value of each of the five sentencing factors for the LightGBM
  model, establishing prior-DUI record and BAC as the dominant factors
  (prior-DUI 1.53 > BAC 1.46 > driving distance 0.79 > offense year 0.65 >
  vehicle type 0.28).

SUPPLEMENTARY FIGURE TITLES & LEGENDS
----------------------------------------------------------------------
Figure S1. Per-class SHAP beeswarm for the long-imprisonment class (class 3).
  Each point is a case; horizontal position is the SHAP value (impact on the
  model's class-3 prediction) and color encodes the feature value (low to high).
  Higher blood-alcohol concentration and more prior-DUI convictions push predictions
  toward the long-imprisonment class, consistent with the global ranking r_ML
  (Figure 3). Vehicle type is shown as its one-hot components. (LightGBM, TreeSHAP.)

Figure S2. Local SHAP explanation (waterfall) for one representative class-3 case
  (case id 4575). Bars show each factor's additive contribution from the base value
  E[f(X)] = -4.648 to the model output f(x) = 1.521; blood-alcohol concentration
  (+3.34) and driving distance (+1.43) dominate for this case. Provided to illustrate
  the per-case decomposition behind the global ranking; it is not used in any
  aggregate claim. (LightGBM, TreeSHAP.)
